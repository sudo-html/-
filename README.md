# 💾 Флешка мастера

Сайт, который помогает подобрать систему для вашего телефона, планшета или ПК и ведёт на **официальные** страницы загрузки.

🌐 **Сайт:** https://sudo-html.github.io/Masterflashka/

## Что умеет

- Поиск устройства по модели (телефоны и планшеты, ~400 моделей)
- Определение подключённого устройства через браузер (WebUSB, Chrome/Edge)
- Подбор системы: LineageOS, Ubuntu Touch и другие, Linux и Windows для ПК
- Пошаговые инструкции и чек-лист подготовки
- Проверка контрольной суммы SHA-256 скачанного файла
- Раздел по кибербезопасности
- Интерфейс на 11 языках

## Важно

- Сайт **не хранит** образы систем и не раздаёт пиратские копии. Все загрузки ведут на официальные сайты.
- Прошивка устройства может стереть данные и привести к потере гарантии. Делайте резервную копию и действуйте на свой риск.
- Не для всех моделей есть официальные сборки. Если модели нет в списке, это значит, что поддержки нет.

## Источники данных

Список устройств собран из открытых проектов LineageOS и UBports.
